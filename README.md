SB-02 — Triangle Solution
Texas Instruments TI-59 keystroke program · Originally developed circa 1979–1981 · TI-5x Android emulator
Solve a general triangle from three suitable known elements (sides and/or angles). This is a revived version of an original TI-59 program from the early programmable-calculator era, using trigonometric relationships including the sine and cosine rules.
The calculator keyboard overlay identifies the sides as a, b, c and the opposite angles as α, β, γ. The D key is labelled `INIT`, and E is labelled `CALC`.
Running the program
Install Pascal Obry's TI-5x emulator for Android.
Download the SB-02 program package from the TI-5x download page and import it into the emulator.
Consult the accompanying help/documentation for the accepted combinations of known elements, entry procedure, possible ambiguous cases, and interpretation of results.
About the project
Triangle Solution predates the author's three newer aviation navigation programs (SB-11, SB-12 and SB-13). Together they illustrate how much numerical work can be done with the TI-59's keystroke-programming model.
